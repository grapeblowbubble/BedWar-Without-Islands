#respawnrules
1、玩家只有在床上绑定了重生点时才能重生，如果死亡时未绑定重生点，则该玩家变为旁观者模式
2、删除床的合成配方
3、玩家只能在X、Z属于正负100的范围内绑定床
4、玩家首次出生时自带一张床，全套皮革盔甲，石剑、石斧、石镐

#BedGuard
1、玩家绑定的床被摧毁时在该玩家的屏幕中心显示“床已被摧毁，你将不能重生”
2、世界创建后的前两分钟禁止pvp，在两分钟后开启pvp并且在所有玩家的屏幕中心显示“pvp已开启”

#TrailCompass
1、为指南针加入附魔“寻迹”：附魔消耗经验：5级
2、附魔了“寻迹”的指南针指向最近的玩家
3、玩家手持寻迹指南针时，在经验条上方用小字显示最近玩家的大致距离（0至10m：“很近”，10至50m：“较近”，50至100m：“较远”，>100m:“很远”）

2、删除追溯指针原本的“指向死亡地点”的功能
3、为追溯指针加入功能：手持追溯指针右键，消耗背包中的一颗钻石，并且至向距离最近的被其它玩家绑定了的床（持续10s，并显示大致距离0至10m：“很近”，10至50m：“较近”，50至100m：“较远”，>100m:“很远”）
